# 🧸 BeBeam

**내가 만든 웹앱을 폰에 담고, 친구와 폰을 맞대어 나누는 플레이어**

👉 **https://www.bebeam.net/**

> ⚠️ 베타입니다. 여러 기기에서 확인하는 중이라 일부 환경에서는 동작이 다를 수 있어요.

바이브 코딩으로 만든 작은 웹앱(게임, 수업자료, 도구)을 **서버 없이** 내 기기에 설치해 실행하고, 친구 화면의 QR을 카메라로 비추는 것만으로 **네트워크 없이** 전송합니다.

## 사용법

### 1. 플레이어 설치
1. https://www.bebeam.net/ 에 접속해 **[플레이어 실행]** 을 누릅니다.
2. 설치하기
   - **PC (Chrome / Edge), Android (Chrome)**: 설치 안내가 뜨면 **[설치]** 를 누릅니다.
   - **iPhone / iPad (Safari)**: 하단 **공유 ⬆︎** → **홈 화면에 추가** 를 누릅니다.
   - Firefox PC는 설치 없이 탭에서 사용합니다.
3. 한 번 설치하면 인터넷 없이도 실행됩니다.

### 2. 앱 추가
목록 아래의 **[＋ 나의 앱 추가]** 를 누릅니다.
- **폴더 추가**: `index.html` 이 들어 있는 폴더를 선택합니다. 폴더 선택을 지원하는 브라우저(주로 PC)에서만 보입니다.
- **zip 파일 추가**: 폴더를 압축한 zip 파일을 선택합니다 (폰에서는 이 방법을 쓰세요).
- **QR로 받기**: 친구에게서 받습니다 (아래 4번).

설치 전에 앱 이름, 파일 수, 크기, 주의할 점(인터넷 파일 사용 등)을 보여 줍니다. 같은 폴더를 다시 추가해도 별개의 앱으로 설치됩니다.

### 3. 실행
목록에서 앱을 고르고 **▶ 재생** 을 누르면 전체화면으로 실행됩니다. 오른쪽 위의 반투명 **✕** 로 종료합니다.

목록의 **⋯** 메뉴에서 **이름 바꾸기 · 전송하기 · 초기화(저장 데이터 삭제) · 삭제** 를 할 수 있습니다.

### 4. 친구에게 보내기 (QR)
1. 보내는 사람은 앱을 고르고 **📤 앱 보내기** (또는 **⋯ → 전송하기**)를 누릅니다. 화면에 QR이 계속 바뀌며 나옵니다.
2. 받는 사람은 목록 아래 **📷 앱 받기** (또는 **＋ 나의 앱 추가 → QR로 받기**)를 누르고, 후면 카메라로 보내는 화면의 QR을 **틀 안에** 비춥니다(15–30cm).
3. 받는 화면에 진행률과 남은 시간이 나옵니다. 잠깐 벗어나도 다시 비추면 이어서 받습니다. **여러 명이 한 화면을 동시에 받을 수 있습니다.**
4. 다 받으면 앱 정보가 나옵니다. 받으려던 앱이 맞으면 **[설치 시작]** 을 누릅니다. 받은 앱은 바로 목록에 추가됩니다.
5. 보내는 사람은 친구들이 다 받은 것을 보고 **[완료]** 를 누릅니다.

반사광이 보이면 폰을 살짝 기울여 주세요. 잘 안 읽히면 보내는 쪽에서 **속도** 를 느리게로 바꿉니다.

## 내 앱을 만들 때

| 지원 | 지원하지 않음 |
|---|---|
| 폴더 맨 위에 `index.html` | `index.html` 이 없는 폴더 |
| HTML, CSS, JS(ES 모듈 포함), JSON | 인터넷의 파일 (CDN 스크립트, 웹 폰트, 외부 API) |
| 이미지, 오디오, 비디오, 폰트, wasm | `indexedDB`, 쿠키, Service Worker |
| `localStorage` 로 점수·설정 저장 | 순환 import, bare import (`import 'three'`) |
| 전체 50MB, 파일 하나 20MB, 파일 1,000개까지 | 그보다 큰 앱 |

**필요한 라이브러리는 CDN 대신 파일로 폴더 안에 넣어 주세요.**

## 주의사항

- **외부 통신은 모두 차단됩니다.** 받은 앱이 내 정보를 밖으로 보내지 못하게 하기 위해서입니다. 인터넷이 필요한 앱(AI API 호출 등)은 동작하지 않습니다.
- **앱은 격리된 공간(샌드박스)에서 실행됩니다.** 앱끼리, 또는 앱이 플레이어의 데이터를 볼 수 없습니다. 그래도 **모르는 사람이 보낸 앱은 받지 마세요.**
- **데이터는 내 기기 안에만 있습니다.** 서버에 백업되지 않으며, 브라우저의 사이트 데이터를 지우면 설치한 앱과 저장된 점수가 모두 사라집니다.
- **iPhone은 반드시 홈 화면에 추가해서 쓰세요.** Safari 탭에서만 쓰면 7일 동안 사용하지 않을 때 데이터가 지워질 수 있습니다. iPhone에서는 실행할 때마다 카메라 권한을 다시 물을 수 있습니다.
- **QR 전송은 암호화하지 않습니다.** 화면의 QR은 근처의 다른 카메라도 읽을 수 있으니, 누구에게 보여도 되는 앱만 보내세요. 받은 파일이 온전한지는 자동으로 확인합니다.
- **2.0부터 전송 방식이 바뀌었습니다.** 1.x 버전과는 주고받을 수 없으니 양쪽 모두 플레이어를 최신으로 업데이트해 주세요.
- **QR 전송은 작은 앱에 알맞습니다.** 압축 후 1MB 앱이 몇 분 정도 걸릴 것으로 예상합니다(기기에 따라 다름). 2MB가 넘으면 예상 시간을 먼저 알려 줍니다. 보내는 화면의 밝기를 최대로 해 주세요.
- **전송할 때 저장된 점수·설정은 함께 보내지 않습니다.** 앱 파일만 전송됩니다.
- 플레이어 주소는 **www.bebeam.net** 입니다(2026-10-27 변경). 이전 주소(`bebeam.mcnorton.com`)에 설치한 앱은 옮겨지지 않으니, 새 주소에서 플레이어를 다시 설치하고 앱을 다시 추가해 주세요.
